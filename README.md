# 📘 About This Repository

This repository is designed to help learners gain practical experience with GitHub concepts covered in the GH‑900 course.

By using this repository you will learn how to:

- Navigate repositories
- Create branches
- Commit changes
- Open pull requests
- Review code
- Resolve issues
- Collaborate using Discussions
- Use GitHub Projects
- Work with GitHub Copilot
- Explore GitHub security features
- Practice Markdown formatting

---

# 🎓 What is GH-900?

GitHub Foundations (GH‑900) introduces learners to the fundamental concepts of Git, GitHub, collaboration, and modern software development practices.

The course is designed for:

- Developers
- Technical trainers
- Project managers
- Technical leads
- DevOps engineers
- Students
- Anyone new to GitHub

No prior GitHub experience is required.
