MODULE /

01

Prove identity

Authentication answers “who are you?” Strong sign-in practices and multi-factor authentication make that answer more trustworthy.

02

Grant access

Authorization answers “what can you do?” Scope access to the smallest useful set of repositories, actions, and settings.

03

Review the boundary

Access is not permanent by default. Revisit roles as responsibilities change, and remove permissions that no longer serve the work.
